# Security

Credentials, token cache, exported health records, menstrual information and activity locations are sensitive. Store the key in a private `.env` or Garmin key file; restrict access to the key and Garmin token cache, encrypt backups, and never commit archives or logs. Do not paste keys into support requests. Delete a compromised or lost key in Garmin Connect and create a replacement; Garmin says deleting the key invalidates its associated tokens. The project sends data requests to Garmin through its official client; dependency installation uses the configured package index.
